# User Story: Login

As a registered customer,
I want to log in with my username and password,
so that I can see the product list and shop.

## Acceptance Criteria
1. Entering a valid username and password and clicking Login opens the products page.
2. Entering a valid username with a wrong password shows an error message and stays on the login page.
3. Leaving the username empty shows the error "Username is required".
4. Leaving the password empty shows the error "Password is required".
5. A locked-out user cannot log in and sees an error message that the user has been locked out.
